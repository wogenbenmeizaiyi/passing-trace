# 好友、共同经历与聊天分享

## 使用入口

- Web 主导航 / App 底部导航的「消息」包含聊天、好友和提醒。好友可通过好友码添加，App 支持扫描好友二维码；自己的码在用户中心及好友页。
- 好友资料里的备注、私人标签仅自己可见；亲密朋友、恋人、家人需对方确认才显示为双方关系。
- 编辑记录时在「一起的人」选择好友，正文输入 `@` 也会打开选择器。仅输入名字不会授权。自己的记录列表不变，可切换「共同参与的」查看别人关联给自己的记录。
- 记录、故事线详情和聊天内都能主动分享。确认接收人后发送只读卡片，接收方看到发送时版本。共同参与记录则跟随作者更新。
- 清除聊天只隐藏自己的历史。停止分享、移除共同参与、删除 / 拉黑好友是独立操作；重新添加不恢复旧授权。

## 权限边界

| 内容 | 作者 | 被关联好友 | 收到主动分享的好友 | 其他人 |
| --- | --- | --- | --- | --- |
| 原始私人记录 API | 读写 | 不可访问 | 不可访问 | 不可访问 |
| 共同记录只读入口 | 按作者权限 | 当前有效关联时可读最新版 | 不自动授权 | 不可访问 |
| 分享专用入口 | 管理本次分享 | 不自动授权 | 好友关系及分享有效时可读固定版本 | 不可访问 |
| 私人备注 / 标签 | 自己可读写 | 不可读取对方设置 | 不可读取对方设置 | 不可访问 |

图片、视频和文件由受认证的只读入口读取，不返回对象存储密钥或永久公共链接。故事线仅带该版本节点指向的记录修订、阶段和连线；不能从节点进入作者其他修订。来源删除、停止分享或好友关系结束后，卡片 / 节点不可查看。已经下载的文件、截图和已展示的回答文本无法追回。

好友关系和参与授权具有并发版本保护。消息、分享授权及提醒一起持久化；同一会话内相同 `clientMessageId` 重试不产生重复消息。HTTP 发送，原生 SSE 提醒；断线按持久化通知游标补齐，前台重新校验已加载分享卡片。会话摘要默认每页 20 条，打开会话仅加载最近 30 条，再按需加载。

## AI 工具包

`FriendsCapabilityPackage` 注册到已有内部 MCP 管道，由现有 schema 与参数校验执行：

- `SearchMyFriends`：昵称、备注、关系查询，同名返回候选。
- `GetMyFriendRelationship`：明确区分私人标签与双方确认关系。
- `SearchMyRecords(participantFriendId)`：本人记录及有效共同记录。普通聊天分享不计参与。
- `AggregateMyFriendActivities`：默认最近 30 天，本月按用户日历；按发生时间统计去重的已完成记录，计划、缺少时间的记录另列。单位为共同记录条数，不推断见面次数、恋人或个人支出。
- `SearchSharedContent`：仅明确询问分享或分享的连续追问时，检索有效的固定分享版本。

证据包含好友候选、统计范围、来源作者和安全的应用内引用。历史引用重新检查权限，社交数据变化更新受影响用户的数据版本；撤销后的证据不会作为后续模型上下文使用。有好友历史的用户绕过问答结果缓存及旧摘要，优先权限安全。工具均为只读，不替用户添加好友、改变关系或发送消息。

## 开发数据与运行

正常使用 `dotnet run --project AppHost/AppHost.csproj` 启动全栈。已有开发初始化流程调用 `tools/seed_development_demo.py`，除原来的记录和故事线外，还创建开发账号专属的好友演示数据：小林、小周和未授权第三人、共同活动、私人标签 / 双方关系、文字聊天及分享卡片。

仅在 Development 且启用默认账号自动登录时可初始化；Identity 根据已配置的开发账号创建带专属标记的配套账号，不读取业务库、不输出密码，也不复用无标记的同名账号。重复运行不覆盖后续编辑、删除和关系设置。

入口：`http://localhost:5173/messages`。可问 AI「最近 30 天和谁的共同记录最多」「第二位是谁」「我和他上次一起做了什么」。

新增迁移：Identity 的 `AddFriendCode`；业务库的 `AddSocialExperiences` 与 `HardenSocialGrants`。发布时两套数据库都需按现有迁移流程更新；不能只发客户端。此次开发未修改生产数据库。

## 验证

- `SocialExperienceTests`：三账号隔离、附件鉴权、实时关联 / 固定分享、删除及重加、关系确认、幂等消息、分页、已读 / 清除、统计去重 / 时间范围、历史证据、固定故事线节点、开发数据门禁、真实 HTTP / SSE。
- `PeopleTests`：认证、公开资料白名单、好友码解析、二维码、批量限制、开发接口的环境限制。
- Web `social.spec.ts`：摘要懒加载、重试幂等、返回聊天草稿 / 滚动、清除与撤回同步、参与者选择、安全引用。
- Flutter `social_test.dart`：认证刷新、消息重试、分页 / 清除、大字体与深浅色参与者选择、AI 引用。
- 本地只读冒烟检查：`python tools/verify_development_social.py`。复用开发自动登录检查好友、摘要、记录 / 故事线分享预览和管理入口，不打印令牌、正文或私人资料。
