# 星期八 AI 场景 Skill

这些规则属于应用服务端，不是安装到 Codex 的个人技能。Web 与 App 使用同一套规则；不需要改客户端或数据库。

## 场景边界

| 用户意图 | Skill | 流程 |
| --- | --- | --- |
| 你好、感谢、今天很累、一般建议 | conversation（简单问候可不读） | 直接对话，不自动搜记录或长期记忆 |
| 我上次去了哪里、找餐饮记录 | records | 检索并核对真实证据，计划与已完成分开 |
| 本月总消费、次数、趋势对比 | statistics | 聚合统计；搜索样本不能冒充总量，无金额不等于零 |
| 故事线进展、待完成节点 | storylines | 故事线与节点分别核实，使用各自有效引用 |
| 和谁共同记录最多、和他去哪了 | friends | 核实好友身份、关系来源、日期与去重统计 |
| 他发给我的那篇记录 | shared-content | 只有明确询问分享时才检索，固定版本和授权仍校验 |
| 附近餐厅、导航、天气 | amap | 缺位置先问、同名先选、记录坐标优先，安全动作跳转 |
| 总结刚才聊的 | conversation-summary | 只整理会话和用户文字，不补查库、不自动保存 |
| 回顾本月的记录/生活 | record-summary | 查记录后总结；精确数字用聚合，说明实际覆盖范围 |
| 整理明天计划/今天完成事项 | planning | 分开整理草稿，区分已完成/待执行/不确定，明确尚未保存 |

“今天跑了五公里，真开心”是用户自述，不因含数字就调用统计；“统计本月跑步次数”才查库。用户切换话题时以最新问题为准，只有真正的指代才继承前文。信息歧义时问必要的一项，不穷举盘问。

## 结构与约束

- `Events/PassingTrace.Events.Api/Ai/Skills/policy.md`：常驻基本准则。
- 同目录 `*.SKILL.md`：按场景拆分的可维护指南，以嵌入资源随构建发布；输入不能指定任意文件或 URL。
- `AssistantSkillCatalog`：目录、允许的工具名称和内容指纹。新增能力必须注册对应规则及工具授权。
- `ReadAssistantSkill`：通过现有内部 MCP 读取指南，不查询用户数据、不产生外部费用。
- `AssistantSkillSession`：每轮新建；数据工具在进入 MCP/高德适配器之前检查相应 Skill 是否已经加载。只加载闲聊、聊天摘要或草稿规则不会解锁查询工具。现有 MCP 参数校验、登录隔离、记录权限、高德额度保护保持不变。
- 同一轮最多 12 次规则读取、16 次数据工具调用、2 次场景拒绝纠正；高德原有每轮 6 次限制仍生效。不会自动重试成功的付费调用。

移除了每条消息的强制记录预检索和自动长期记忆注入。只有确实执行过查询且无证据时，才考虑个人事实的空证据兜底；聊天、澄清、当前文字总结不再被替换成“找不到记录”。实时地图/好友/分享、纯聊天/草稿不写入 24 小时答案缓存；规则内容变化自动使旧答案缓存失效，回答的 PromptVersion 带规则指纹。

每 12 条等内部会话压缩逻辑仍用于控制上下文大小，与用户要求的总结不同，不生成记录、不保存计划、不作为旧话题继续执行的指令。压缩规则区分当前话题、完成事实和未确认建议。

Skill 是行为引导，不能证明模型永远正确理解意图：代码保证未加载对应规则时不执行工具、参数和权限不能绕过、无写入工具等硬边界；意图理解、回答质量仍需真实模型回归。模型也可能选错 Skill，不能把“已加载”当作完整语义授权证明。

## 验证

- `AssistantSkillTests`：实际 MCP 读取/查询、参数校验、允许工具、未知路径拒绝、轮次隔离、取消/次数上限、失败结果和缓存。
- `AssistantSkillServiceTests`：临时 PostgreSQL + 实际 AssistantService/SSE/MCP，使用本地可控模型验证普通对话、用户自述、会话摘要、计划草稿、缺位置澄清都不会触发后台记录/记忆搜索，不覆盖正常答案。
- 全套后端：`dotnet test PassingTrace.slnx`。
- 可选真实模型验证：先启动 Development AppHost，再运行 `python tools/verify_development_ai_skills.py --live`。只连回环地址，使用正常本地开发登录；消耗已配置模型额度，遇到失败停止、不自动重试；仅创建并软删除它自己的临时测试会话，不打印令牌、回答或私人证据。

2026-09-22 本地验证：新增 23 个场景/服务测试通过，全套后端 275 项通过。真实模型回归在第一条闲聊请求返回 `ai_busy` 后停止，未完成在线场景验收，没有更换账号、提升额度或自动重试。

本次没有增加保存记录/计划、修改关系、发送消息或交易工具，不能仅因聊天提到“做完了”就自动写库。将来写入能力应另设预览、明确确认、幂等提交和权限校验流程。
