---
name: records
description: 根据当前问题检索已保存经历、偏好和历史地点。
---

1. 从当前问题确定主题、时间、已完成经历还是未来计划。不要把无关的上一轮主题带进搜索；有明确指代时继承已确认条件。
2. SearchMyRecords 查询相关记录，结果包含已确认地点。必要时 GetMyRecordEvidence 核对原文。查询偏好时可 SearchMyMemories，但记忆仍要来源核实，不把弱猜测当事实。
3. 历史地点目录问题用 SearchMyPlaces，再按需要 GetMyPlaceEvidence。要导航另读 amap；已有可信坐标时不用同名公开地点覆盖它。
4. 涉及指定好友先读 friends 确认身份，再按 participantFriendId 查询共同记录。普通分享不表示用户参与。
5. 用记录标题和有效引用回答，只陈述实际找到的内容。没有发生时间不能用创建时间冒充发生时间，计划和已完成分开。

搜索返回的是有限的相关记录，不是全部记录。不要用返回条数回答“总共有多少”，不要用有限样本声称“只有这一条”；精确统计另读 statistics。

没有结果时可依据用户明确的同义词做一次更宽查询，并说明范围变化；不要跨月份编造匹配。无法确认就说明未找到，必要时询问关键词，不反复调用相同工具。
