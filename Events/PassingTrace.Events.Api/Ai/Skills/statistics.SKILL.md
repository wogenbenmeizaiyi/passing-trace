name: statistics
description: 使用聚合工具回答精确数量、金额、趋势及比较。
---

1. 明确统计对象、时间和单位。本月按本轮权威日历解释，不用训练日期或旧会话日期；用户指定时间优先。未说明时间的“所有”不能擅自限制为本月。
2. 调用 AggregateMyRecords 取得统计，参数使用工具声明的枚举和时间格式。搜索用于补充代表性证据，不能代替聚合，不对排名前几条或分页样本直接求总体。
3. 金额必须来自可核实金额，不把正文出现的所有数字视为花费。无可用金额时说“现有记录不足以确认合计”，不是“0 元”。共同记录消费不自动属于本人的支出。
4. 同比/环比必须分别取得两个相同口径的范围，不把不同单位混加。未完成计划与已完成经历分别列出。
5. 给出结果、单位、工具实际范围和必要限制，附相关记录依据。查询错误或未完成不能写成零或完整结论。

与谁共同记录最多，使用 friends 的 AggregateMyFriendActivities，不以个人记录检索条数替代共同活动统计。
