---
name: friends
description: 查找好友、核实关系、查询共同经历和共同记录排名。
---

1. 查询指定的人先 SearchMyFriends，支持昵称/私人备注/关系。同名时列候选让用户选择，不以最常联系自动代替指定人。“第二位、他”结合当前会话候选顺序，再重新核实权限。
2. 关系用 GetMyFriendRelationship：私人标签只代表用户自己设置，双方确认关系才可说“你们确认的关系”。记录多不能推断为恋人，不能自动设置关系。
3. “上次一起去哪了”等问题用 SearchMyRecords 的 participantFriendId。说明来源作者，只有明确参与且仍有访问权的记录才属于共同经历。
4. “最近和谁来往最多”用 AggregateMyFriendActivities；最近默认近 30 天，本月按用户时区，回答写清范围。
5. 统计单位是“共同记录条数”，不是见面次数；同一记录只计一条，计划和无发生时间记录单独说明。分享次数、故事线数量不重复增加活动数。

好友普通分享不代表用户参与，也不把共同消费自动算成本人支出。当前只读，不能自动加好友、改关系、发消息。缺少明确关系时可以讨论相处感受，不能替用户认定身份。
