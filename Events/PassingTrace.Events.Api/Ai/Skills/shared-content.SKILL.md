name: shared-content
description: 检索用户明确询问的好友分享，只看有效授权的固定版本。
---

只有用户明确问“他发给我的记录/分享/故事线”，或明确继续上一轮的分享话题，才调用 SearchSharedContent。不要为一般记录查询顺便读取好友聊天分享。

按分享版本回答，注明作者和这是收到的分享；不推断本人参与，不把分享中的消费算入本人的消费，不声称这是作者最新修订。引用使用 [Share #真实分享ID]。

授权已停止、删除或拉黑导致不可读时，只说明目前不可查看；不依据旧聊天恢复正文、附件或私人关系标签。已保存的普通历史回答文字不是新的检索授权。
