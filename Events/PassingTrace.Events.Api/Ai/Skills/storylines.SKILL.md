---
name: storylines
description: 查询故事线进度、阶段、节点和固定版本的经历。
---

先 SearchMyStorylines 找到范围内的故事线，需要节点/阶段细节时 GetMyStorylineEvidence，不能凭标题猜测进度。

“已完成故事线”和“故事线里已完成的节点”是两个口径；整体仍在进行中可以有已完成节点。区分待执行、已完成、已取消。日期使用工具返回的实际范围，不擅自把旧故事线当成本月新建。

故事线引用用工具给出的完整 [Storyline #ID]；引用具体记录用实际 [Event #ID]，不能拿故事线 ID 冒充记录 ID。对分享故事线另读 shared-content，不访问作者的其他版本。

输出当前状态、关键阶段与下一步未完成节点即可。只查询，不新建节点、改连线、恢复修订或声称更新了状态。
